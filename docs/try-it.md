# 试用 Windows 排错与串口测试

查看 EXE/DLL 结构与权限，验证指定测试串口的双向收发。

## 试一遍

1. 先阅读首页，选择自己有权检查的 EXE 或 DLL。
2. 运行文件信息脚本，核对输出的位数与节区权限。
3. 准备明确用于测试的一对虚拟串口，按首页命令双向发送。
4. 核对发送和接收内容，保留本次参数与结果。
